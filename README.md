# Python To-Do App

A simple and clean To-Do web application built using **Python (Flask)** and containerized with **Docker**.

# Features

* Add tasks
*  Mark tasks as complete
*  Delete tasks
*  Run using Docker

## Tools Used
- Python
- Flask
- Docker
- Docker Compose
- GitHub

## Steps to Run

Steps to Run the Application:
 1. Open terminal
 2. Navigate to project folder
 3. Run command:
    docker-compose up --build
 4. Open browser:
    http://localhost:5000

## About this task:

This project is created for learning purposes and basic understanding of Flask and Docker.
