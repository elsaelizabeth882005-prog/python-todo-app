# Python To-Do App

A simple and clean To-Do web application built using **Python (Flask)** and containerized with **Docker**.

# Features

* Add tasks
*  Mark tasks as complete
*  Delete tasks
*  Run using Docker

## Tools Used
- Python
- Flask
- Docker
- Docker Compose
- GitHub

## Run the app

  Run command:
      docker-compose up --build
 

## About this task:

This project is created for learning purposes and basic understanding of Flask and Docker.
